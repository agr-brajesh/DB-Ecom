# Agent Guidelines for DB-Ecom / NexusAI

## Git Operations (STRICT)
- **NO AUTOMATIC GIT COMMITS OR PUSHES**:
  - Never run `git add`
  - Never run `git commit`
  - Never run `git push`
  - All staging, committing, and pushing to GitHub/remote repositories must be done manually by the user.
  - When completing a phase, task, or bug fix, summarize the changes and leave the files unstaged in the working directory for user review.
